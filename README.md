# Tourism Insights — Data Science Internship

## Overview
This repository documents my six-week tourism data science internship, focusing on tourism statistics, exploratory data analysis, trends, and visualizations.

## Project Structure

### Week 1 — Data Collection
- `Week 1 - Data Collection/Data/` — Original tourism source data retained locally.
- `Week 1 - Data Collection/Report/` — Data collection report and remediation addendum.

### Week 2 — Exploratory Data Analysis
- `Week 2 -EDA/data/` — Structured CSV datasets.
- `Week 2 -EDA/notebooks/` — Jupyter notebook for EDA.
- `Week 2 -EDA/visualizations/` — Generated charts.
- `Week 2 -EDA/Report/` — EDA report.
- `Week 2 -EDA/generate_charts.py` — Chart-generation script.

## Tools
- Python
- Pandas
- Matplotlib and Seaborn
- Jupyter Notebook

## Data Source
Ministry of Tourism, Government of India: https://data.tourism.gov.in/rawdata

## Progress
- Week 1: Data collection and strategy planning.
- Week 2: Exploratory data analysis, visualizations, and reporting.

## Reproducibility
Required Python dependencies should be installed before running the notebook or chart-generation script. A requirements file can be added after confirming the project's dependencies.
