\# Tourism Insights — Data Science Internship



\## Overview

This project analyzes international tourism trends and India's inbound tourism using official tourism statistics.



\## Project Structure

\- `Week 1 - Data Collection/Report/` — Week 1 research and remediation reports.

\- `Week 2 -EDA/data/` — Cleaned and structured CSV datasets for exploratory data analysis.

\- `Week 2 -EDA/notebooks/` — Jupyter notebook containing EDA.

\- `Week 2 -EDA/visualizations/` — Generated charts.

\- `Week 2 -EDA/Report/` — EDA report.

\- `Week 2 -EDA/generate\_charts.py` — Python chart-generation script.



\## Tools

\- Python

\- Pandas

\- Matplotlib / Seaborn

\- Jupyter Notebook



\## Data Source

Ministry of Tourism, Government of India — official tourism statistics and raw data portal: https://data.tourism.gov.in/rawdata



The original source PDF is retained locally and excluded from this repository because of its size.



\## Project Status

\- Week 1: Data collection and strategy planning.

\- Week 2: Exploratory data analysis, visualizations, and reporting.



\## Reproducibility

Install the required Python libraries before running the notebook or chart-generation script. A requirements file will be added after confirming the project's actual dependencies.
